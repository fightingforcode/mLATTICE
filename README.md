# mLATTICE
mLATTICE: A Deep Learning Framework with Label-Specific Feature Learning for Imbalanced mRNA Subcellular Localization Prediction
# Notes:
1. The DNABERT2 model can be downloaded from Hugging Face, then rename its folder to DNABERT2_attention and place it in the root directory.
2. The trained model and datasets are uploaded to [Google Drive](https://drive.google.com/drive/folders/1D-L1-kJcjiAl4lYxrvl6yNF05CjhsClP?usp=drive_link)
3. If you need to use our tool, please directly access the webserver at http://47.96.9.233:8082.
# Usages:
To use the mLATTICE model, run the following command:
`python pipeline.py --input_path data.fasta`
